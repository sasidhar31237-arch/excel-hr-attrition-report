# HR Attrition Analysis (Excel)

Analyzed a 1,470-employee HR dataset using Excel to identify attrition patterns and salary trends, 
using pivot tables, formulas, and charts.
## Techniques Used
- Pivot Tables: attrition rate by department, average income by job role, attrition by job satisfaction level
- Formulas: AVERAGE, MAX, MIN, COUNTA, COUNTIF for a summary dashboard
- Nested IF formula: categorized employees into Salary Bands (High/Medium/Low)
- Chart: clustered column chart visualizing attrition rate by department
- Data cleaning: verified no duplicate or missing records across 1,470 rows
## Key Findings
- Average monthly income: 6,502.93
- Highest attrition department: Sales at 20.63%, followed by HR at 19.05% and R&D at 13.84%
- Total employees analyzed: 1,470
- Salary bands categorized using a nested IF formula (High ≥ 10,000, Medium ≥ 5,000, Low < 5,000)
## Dataset
IBM HR Analytics Employee Attrition dataset (Kaggle, 1,470 rows, 35 columns)
